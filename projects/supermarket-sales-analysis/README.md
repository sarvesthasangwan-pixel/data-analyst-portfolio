
Supermarket Sales Analysis

Project Overview

This project analyses supermarket sales data to identify sales trends, product performance and business insights.

Objectives

- Calculate total revenue.
- Identify the best-selling products.
- Compare sales across product categories.
- Analyse monthly sales trends.
- Identify opportunities to improve business performance.

Tools

- Python
- Pandas
- Matplotlib
- Jupyter Notebook

Skills Demonstrated

- Data exploration
- Data cleaning
- Data manipulation
- Statistical analysis
- Data visualisation
- Business insights

Project Status

Planned – practical analysis and findings will be added as the project develops.
