Supermarket Sales Analysis

Project Overview

This project analyses supermarket sales data to identify sales trends, customer spending patterns, product performance and business insights.

The aim is to explore sales data using Python and identify useful information that can support business decision-making.

Objectives

- Calculate total revenue.
- Identify the highest- and lowest-revenue product categories.
- Compare sales performance across branches.
- Analyse monthly revenue trends.
- Understand customer purchasing patterns.
- Compare revenue across payment methods.
- Identify opportunities for business improvement.

Tools and Technologies

- Python: Programming and data analysis.
- Pandas: Data cleaning, manipulation and analysis.
- Matplotlib: Data visualisation.
- Google Colab: Writing and running Python code.
- GitHub: Project storage and documentation.

Dataset

- 1,000 supermarket transactions.
- 17 original columns.
- Includes product categories, customer information, payment methods, sales totals and ratings.

Note: This is simulated teaching data, not actual company sales data.

Analysis Performed

- Data inspection and quality checks.
- Missing value analysis.
- Date conversion and monthly analysis.
- Revenue analysis by product category.
- Branch performance comparison.
- Customer type analysis.
- Payment method analysis.
- Customer ratings analysis.
- Data visualisation using charts.

Key Findings

- Total revenue: 322,966.75.
- Food and Beverages generated the highest product category revenue: 56,144.84.
- Health and Beauty generated the lowest product category revenue: 49,193.74.
- Branch C generated the highest revenue: 110,568.71.
- January recorded the highest monthly revenue: 116,291.87.
- Members accounted for 50.1% of transactions.
- Members had a higher average transaction value (327.79) than Normal customers (318.12).
- Cash generated the highest revenue among payment methods: 112,206.57.

Business Recommendations

- Investigate the factors contributing to strong Food and Beverages sales.
- Examine the reasons for the February revenue decline.
- Explore customer loyalty strategies.
- Continue supporting different payment methods.

These recommendations are suggestions for further investigation, not proven causes.

Conclusion

This project demonstrates practical skills in data cleaning, data analysis, data aggregation and data visualisation using Python.

It also demonstrates how data analysis can be used to identify patterns and communicate business insights.
